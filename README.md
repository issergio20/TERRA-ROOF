# Terra Roof — лендинг кровельного подрядчика

Одностраничный сайт на чистых HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

Открыть `index.html` через любой локальный сервер, например:

```bash
python -m http.server 5500
```

и перейти на http://localhost:5500.

## Структура

- `index.html` — разметка всех блоков, окна кейса и расчёта стоимости
- `styles.css` — стили; размеры масштабируются от макета 1440px через `clamp()`
- `main.js` — меню, окна, курсор, плавный скролл, формы заявки
- `cases-data.js` — подробные описания кейсов для окна кейса
- `img/` — фото объектов, фон первого экрана (`hero-*.webp`), логотип

## Что нужно доделать

- Отправка заявок: сейчас формы показывают «Заявка отправлена», но данные никуда не уходят (`TODO` в `main.js`).
- Прайс-лист: положить файл в `files/price-list.pdf`.
- Тексты блоков после первого экрана и описания кейсов — черновик, нужно согласовать с копирайтером.
- Ссылки на Telegram, Max и политику конфиденциальности — заглушки `#`.

После правок CSS и JS поднимите метку версии `?v=` в `index.html`, иначе браузер может показать старую версию из кэша.
